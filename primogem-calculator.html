How To Calculate Pulls Before a Banner

Start with your current Primogems and Intertwined Fates, then add the income you can realistically collect before the banner ends. Current pity matters because it already counts toward your next 5-star.

How Many Wishes Should You Save?

If you only want one 5-star attempt, use 75-90 wishes as the planning range. If you want to guarantee the featured limited character from zero pity and no guarantee, use 180 wishes as the safe worst case.

Primogem Calculator FAQ

How many Primogems do I need for one wish?

One wish costs 160 Primogems. This calculator converts Primogems, Intertwined Fates, Genesis Crystals, and extra Fates into a single wish estimate.

How many wishes guarantee a featured 5-star character?

The safest worst-case number is 180 wishes if your next 5-star is not guaranteed. If your next 5-star is guaranteed, you can plan around 90 wishes or less depending on current pity.

Does current pity reduce how many wishes I need?

Yes. If you have 40 pity, you need up to about 50 more wishes to reach 90 hard pity. The calculator includes pity in the progress bars.

Should I include Welkin Moon?

Include Welkin only for the days it will be active. If you are unsure, leave it off first and treat the result as a safer estimate.
